원작 본편 완결 범위를 참고한 비공식 주술회전 텍스트 RPG입니다. 이야기와 가챠·등급·환생·전투 수치는 게임용입니다. 작품의 모든 술식과 몬스터를 빠짐없이 구현했다는 뜻은 아닙니다.

## v2.6 · 옥견의 계승

수련장 → 십종영법술에서 백·흑을 함께 또는 따로 동행시킬 수 있습니다. 소환체 HP가 0이 되면 해당 개체만 파괴됩니다. 백의 힘을 이은 흑은 옥견 · 혼이 됩니다. 흑이 먼저 파괴되는 경로와 백 계승형 디자인은 본편에서 확인되지 않은 게임 확장입니다. 두 마리 모두 파괴되면 재소환할 수 없습니다. 단순 소환 해제·패배는 파괴가 아닙니다.

기존 v2 저장은 그대로 읽습니다. 구판에 옥견 파괴가 기록되어 있으면 이전에 두 개체 전체가 소멸한 판정을 유지합니다. 환생은 새 삶이므로 식신 상태도 초기화합니다.

히구루마의 재판 술식, 천사의 술식 소멸, 우로의 하늘 조작, 이시고리의 주력 방출, 메이메이의 흑조조술, 메카마루의 괴뢰 조술이 뽑기와 개발자 도구에 추가됐습니다. 새 계열마다 기본 행동과 확장기 2종이 있습니다. 신규 적 6종을 만나는 레벨 기반 외전 5개를 추가했습니다. 원작 기반 확장기와 게임용 응용기는 도감 설명을 확인하세요.

픽셀 모델 총 64종. 새 모델 16종을 포함한 모든 이미지를 HTML에 내장했습니다. 네트워크·외부 이미지·별도 설치 없이 index.html 하나로 실행됩니다.

## 플레이 방법

캐릭터 생성 → 이름 → 네 번의 d100 → 자유 스탯 배분 → 운명 확정. 첫 뽑기권은 10장입니다. 확정 후 다음 환생까지 뽑을 수 없습니다. 임무 게시판에서 본편 15개·외전 5개에 도전하세요. 전투 중 상대의 다음 행동이 표시됩니다.

환생 요구 레벨은 50, 100, 150…으로 올라가며 1000에서 고정됩니다. 환생마다 다음 생 기본 스탯 +2, 뽑기권 +10장, 환생 횟수 제한은 없습니다. 임무 완료 또는 조우 당시 자신보다 레벨·등급이 모두 높은 주령 토벌로 승급합니다.

설정 → 개발자 코드 726: 가문·체질·술식·레벨·마스터리 변경, 조건에 맞는 기술·보급 해금. 저장 파일 내보내기와 불러오기를 지원합니다. 로컬 파일과 GitHub Pages의 브라우저 저장소는 다르므로 이동하려면 저장 파일을 사용하세요.

## 배포

GitHub Actions의 Pages 워크플로가 main의 index.html을 배포합니다. GitHub 저장소 Settings → Pages의 소스는 GitHub Actions입니다. 공개 링크는 위의 바로 플레이를 사용하세요.
