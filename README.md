## GitHub 링크로 플레이하게 만들기

1. GitHub에서 공개 저장소를 만들거나 사용할 저장소를 엽니다.
2. `index.html`과 `.nojekyll`을 저장소 최상위에 업로드합니다. ZIP 파일 자체를 업로드하는 것이 아니라 압축을 풀고 파일을 업로드하세요.
3. 저장소의 **Settings → Pages → Build and deployment**로 이동합니다.
4. **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)**를 선택하고 **Save**를 누릅니다. 실제 기본 브랜치가 다르면 해당 브랜치를 선택하세요.
5. 배포가 끝나면 같은 페이지에 표시되는 `https://계정명.github.io/저장소명/` 주소로 접속합니다. 이 링크를 공유하면 다른 사람도 설치 없이 플레이할 수 있습니다.

GitHub의 파일 보기 주소(`github.com/.../blob/.../index.html`)는 플레이 주소가 아닙니다. 반드시 **GitHub Pages 주소**를 사용하세요.

공식 안내: [GitHub Pages 게시 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

### 선택: GitHub Actions 배포

동봉한 `.github/workflows/pages.yml`을 같은 경로에 업로드하고 Settings → Pages의 Source를 **GitHub Actions**로 설정하면 `main` 브랜치에 푸시할 때 자동 배포됩니다. 위의 브랜치 방식과 둘 중 하나만 사용하세요. 기본 브랜치가 `main`이 아니라면 워크플로의 branches를 바꾸세요. 이 방식은 최초에 저장소의 Pages 설정을 활성화해야 합니다.

## 플레이 팁

임무 출격 시 HP·MP가 전부 회복됩니다. 적의 다음 행동을 읽고 대응하세요. 영역전개 때는 전투가 멈추며 맞영역·간이영역·탈출·기점 파괴를 선택합니다. 포창신은 본체 타격, 마히토는 관찰이나 영혼 타격, 카시모는 접지, 스쿠나의 공간 참격은 회피 또는 방해가 핵심입니다.

반전·영역은 처음부터 사용할 수 없습니다. 흑섬 또는 체력 25% 이하의 사선 경험으로 각성 단서를 얻으세요. 실패한 각성은 수련장에서 연구할 수 있습니다. 무술식은 간이영역으로 시작하며, 육체 천여주박은 주술 대신 주구를 사용합니다. 완료한 임무를 반복해 레벨과 보급품을 준비할 수 있습니다.

## v2.1 · 정통 계승 / 개발자 도구

가문과 맞는 술식이면 뽑기 결과와 상태창에 **정통 계승**이 표시됩니다. 기존 저장 캐릭터에도 현재 조합에 따라 자동 적용됩니다.

| 가문 | 계승 술식 |
|---|---|
| 고죠 | 무하한 |
| 젠인 | 십종영법술, 투사주법 |
| 카모 | 적혈조술 |
| 이누마키 | 주언 |
| 스가와라노 미치자네 직계 | 모방 |

효과: 술식 피해 ×1.2, 술식 MP 비용 ×0.85, 술식 숙련 획득 ×2. 일반 가문과 무술식에는 계승 보너스가 없습니다. 육체 천여주박의 주술 금지와 무육안 무하한의 페널티는 유지됩니다.

술식 마스터리는 각 술식별로 Lv.1~100입니다. 유효한 술식 행동(명중 실패도 포함)으로 숙련 1, 계승이면 2를 얻고 10마다 1레벨 오릅니다. Lv.1 대비 레벨당 피해 +1%, 술식 MP −0.2%이며 계승과 곱연산합니다. 반전술식·간이영역 등 공통 기술에는 술식 전용 비용 할인이 붙지 않습니다. 영역전개는 할인과 피해 보너스를 적용합니다. 술식 접촉 공격에서 흑섬이 나오면 기존 흑섬의 기본 위력 2.5제곱 판정을 우선합니다.

**사용법: 우측 상단 ⚙ 설정 → 개발자 코드 → 726 입력 → 코드 확인.** 코드 해금 후 캐릭터를 등록하면 개발자 도구를 사용할 수 있습니다.

- 가문·생득술식·신체 체질 자유 변경
- 캐릭터 레벨 1~1000, 선택 술식 마스터리 1~100 조정
- 간이영역·반전술식·영역 및 레벨 제한 확장기 해금
- 모든 임무 출격 해금 (완료나 보상을 자동 지급하지 않음)
- 모든 주구·식신·모방 술식 해금
- 주전 100만 / 회복·해독·혈액팩 각 999 지급
- HP·MP 전부 회복, 개발자 메뉴 다시 잠그기

변경은 전투 밖에서 가능하며 저장됩니다. 술식마다 숙련도를 따로 보관합니다. 가문·체질·레벨의 기본 스탯을 재계산하고 기존 수련·분배 보너스를 유지하므로 반복 적용해도 스탯이 누적되지 않습니다. 레벨 조정 시 해당 레벨 경험치는 0으로 설정됩니다. 최초 뽑기 주사위는 변경하지 않고 개발자 조정 사실을 기록합니다. 육체 천여주박은 술식 없음만 선택할 수 있으므로 술식을 쓰려면 체질도 변경하세요. 개발자 메뉴를 잠가도 이미 적용한 변경은 유지됩니다. 이 코드는 로컬 게임 편의 기능이며 서버 인증은 아닙니다.

## v2.2 · 환생 / 뽑기권 / 실적 승급

- 최초 뽑기는 10회. 1차 환생 20회, 2차 30회처럼 생마다 한도가 10회 늘어납니다. 새로고침·저장 이전으로 사용한 횟수가 복구되지 않습니다.
- 한 번 뽑을 때 d100 네 번을 굴리고 뽑기권 1회만 소모합니다. 마지막 후보는 횟수가 0이어도 자유 포인트를 분배하고 등록할 수 있습니다. 운명을 확정하면 일반 뽑기는 다음 환생까지 잠깁니다.
- 환생 조건은 첫 50레벨, 다음 100·150·200·250… 순서입니다. 요구 레벨은 1000에서 고정되어 이후에도 환생을 계속할 수 있습니다. 최대 캐릭터 레벨 1000, 환생 횟수 제한 없음.
- 환생마다 영구 기본 스탯 +2. 새 생 기본 스탯은 5 + 환생 횟수 ×2에 가문·체질·초기 MP 보너스를 더합니다. 육체 천여주박 MP 0과 육안 제어 MAX는 유지합니다.
- 유지: 이름, 주전·보급품·주구, 술식별 마스터리, 술사 등급·승급 실적. 초기화: 레벨 1, 가문·체질·술식, 수련·각성·식신·모방·손가락·스토리 완료. 이전 생의 남은 뽑기권은 이월하지 않고 새 한도를 지급합니다.
- 메뉴 **환생·승급**에서 관리합니다. 환생 직전 확인 화면과 저장 내보내기를 제공합니다. 정상 플레이의 확정 운명은 바꿀 수 없으며, 기존 726 개발자 조정은 예외로 유지합니다. 전체 기록 초기화도 개발자 메뉴 해금 시에만 표시합니다.
- **반복 토벌**: 적 레벨 1~1000과 등급을 직접 선택합니다. 승리하면 경험치·주전·임무 완료 1회를 얻습니다. 고레벨 성장을 위한 반복 콘텐츠입니다.

### 자동 승급표

| 다음 등급 | 누적 임무 완료 | 또는 현재 등급에서 상위 주령 처치 |
|---|---:|---:|
| 3급 | 3회 | 3체 |
| 준2급 | 8회 | 4체 |
| 2급 | 15회 | 5체 |
| 준1급 | 25회 | 6체 |
| 1급 | 40회 | 8체 |
| 특급 | 60회 | 10체 |

둘 중 하나만 충족하면 자동 승급합니다. 상위 주령은 **조우 당시 자신보다 레벨도 높고 등급도 높은 주령**만 인정합니다. 주저사·식신 조복은 제외합니다. 한 적을 중복 계산하지 않습니다. 승급하면 상위 토벌 카운트는 0으로 돌아가며 누적 임무 횟수는 유지됩니다. 연전은 적마다 토벌 실적을 계산하고 임무 완료는 최종 승리 한 번으로 계산합니다. 패배·철수는 임무 완료로 계산하지 않습니다. 최대 레벨에서도 임무 횟수로 승급할 수 있습니다.

기존 저장은 레벨·기존 등급을 유지하며 새 실적 시스템으로 이전합니다. 과거 반복 임무 횟수는 저장되어 있지 않아 확인 가능한 완료 목록 수만 이전합니다. 기존 미확정 후보의 남은 뽑기권은 10에서 저장된 뽑기 횟수를 차감하며, 이미 10회 이상 썼다면 현재 후보를 확정할 수 있습니다.

검증: 기존 42개 검사와 환생·승급·토벌·저장 관련 16개 검사 통과. 실제 브라우저에서 환생 전후 10→20회, 기본 스탯 +2, 새 운명 확정, 반복 토벌 보상·실적 반영을 확인했습니다.
